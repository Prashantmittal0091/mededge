Technical Specifications & Project Architecture

B.Tech CS Capstone Project

Hardware & Signal Processing Pipeline

  • Sensors: MAX30102 (SpO₂ & PPG) + AD8232 (Single-Lead ECG Front-End).
  • Digital Signal Processing: SciPy 3rd-order Butterworth bandpass filter (0.5Hz – 40Hz) for 50Hz noise reduction and baseline wander suppression.
  • Fallback Mode: NumPy synthetic PQRST waveform generator for offline testing.

Backend, SLM & Database Architecture

  • Backend Engine: FastAPI with asynchronous WebSockets for 100ms real-time telemetry streaming.
  • Local AI Engine: Quantized Phi-3 Mini SLM (via Ollama / embedded engine) producing contextual clinical alerts with zero cloud latency.
  • Data Persistence: Persistent SQLite database with SQLAlchemy ORM logging vitals, alerts, and audit records.
